### Hey, I’m Kaleb 👋

I build the layer between complex systems and the people who have to operate them. For 15+ years that’s meant operator interfaces, access models, automation and measurement, mostly in PHP and JavaScript and increasingly on Cloudflare.

### 🧱 Projects
- **FpD Metric Collector**: an in-house Lighthouse service on Cloudflare Workers that replaced a third-party scoring tool and turned ad-hoc monthly checks into a repeatable baseline
- **gay.toronto Discord**: a Python bot plus the automation, verification and moderation systems around it, built so the volunteer mods run the server without me
- **kaleb.codes**: my personal publishing platform and writing archive, on Astro, Tailwind and Vercel

### 🧩 Outside of work
I’m drawn to structured creativity- collaborative worldbuilding, system-driven games like *Factorio*, and media that’s a little weird but built to make sense- stories with emotional weight, hidden logic, and something worth unpacking.
